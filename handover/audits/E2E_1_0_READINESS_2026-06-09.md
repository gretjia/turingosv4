## 1. Method (the systematic, multi-dimensional E2E)

A purpose-built workflow ran two independent **user-sim personas** as a
`pipeline(drive → observe)`, each a black-box shell user of the real product
binary (`target/debug/turingos`), plus a **top-level observer agent** per persona
that read the canonical tape:

| Persona  | Entrypoint   | App described (in the user's own words)                          | Exercises |
|----------|--------------|------------------------------------------------------------------|-----------|
| webgame  | `index.html` | a single-page browser Snake game with a "New Game" restart button | HtmlParses + functional gate |
| pyscript | `main.py`    | a Python CSV summary-stats script printing an "Average:" line      | PythonParses + functional gate |

Each persona ran the **full real ladder** (no mocks): `init` → `llm config`
(SiliconFlow default: DeepSeek-V3.2 meta + Qwen3-Coder-30B blackbox) → export
`SILICONFLOW_API_KEY` from `.env` (value never echoed) → write 8 natural-language
interview answers → `spec` (real **Meta LLM** synthesizes `spec.md`) → `generate
--tdma-bounded` (real **Blackbox LLM** generates the artifact, runs the spec-
derived test battery, admits the market) → delivery. The observer then ran
`turingos observe` + `verify chaintape` + artifact inspection.

The E2E ran **three rounds** (round 1 + 2 surfaced defects; round 3 confirmed the
fixes). All real LLM calls; the user authorized the API run.

## 3. Defects found by the E2E and fixed in-loop

All fixes are Class-2, zero trust-root / pinned change, on the unmerged PR #338
branch; each has a mutation-proven regression test.

| # | Round | Defect | Root cause | Fix |
|---|-------|--------|------------|-----|
| 1 | 1 | webgame `generate` exit 2 on a **correct** Snake game | functional needle derived from the spec was the **entrypoint filename** `index.html` (a correct page never prints its own filename) | reject filename/extension tokens as needles |
| 2 | 1 | pyscript `generate` exit 2 on a **correct** script | needle was `python3 main.py` (a **usage/command** example) | reject interpreter/command-prefix tokens (`python3 `/`node `/`./`/…) |
| 3 | 2 | pyscript still exit 2 | needle was `10, 20, 30` / `Average: 20.0` (**raw input data / computed value** lifted from a Given/When/Then example) | reject value/data tokens (no-letter or any-digit) |
| 4 | audit | test-mirror re-introduced the old leaky C11 rendering | `tape_relay_feedback_loop.rs` replica did not route through `shielded_feedback` | route the replica through the single shielded renderer |
| 5 | smoke | `observe` on an un-generated workspace gave a cryptic `pinned manifest: No such file` | guard only checked the (post-`init` empty) `runtime_repo` dir exists | check `pinned_pubkeys.json`; emit a clean "run generate first" message |

Defects 1–3 are the same class (the anti-Goodhart functional gate's needle was
derived from the **first quoted token in fuzzy LLM-synthesized prose**, which is
frequently a filename / command / data value, not a user-visible control). The
unified fix (`is_non_functional_token`) makes a functional needle require a clean
alphabetic, digit-free **label** (`New Game`, `Count:`, `Average:`); everything
else is skipped, and when no clean label is body-quoted the gate safely degrades
to **structural-only** (never false-rejecting correct work).

## 5. Honest limitations (NOT flow-breaking; tracked for future hardening)

1. **Functional anti-Goodhart gate is best-effort.** Its needle is derived from
   non-deterministic LLM-synthesized prose, so it fires only when the spec body
   quotes a clean control/output label; otherwise the run delivers on the
   structural gates alone. It never false-rejects correct work now, and the gate
   is non-vacuous **when it fires** (proven by `functional_gate_rejects_wrong_
   passes_right`), but the anti-Goodhart check is **not guaranteed on every
   spec**. **Recommended next hardening:** derive the required-control needle
   from the **structured interview answer** to the "single most important
   control" question (a reliable, deterministic source) rather than scanning
   prose. This is a separate scoped change to the (audited) delivery gate and was
   deliberately NOT bundled here.
2. **Needle picks the first clean label, not necessarily the user's primary one**
   (round-2 webgame validated "Game Over" while the user emphasized "New Game";
   both were present, delivery correct). Same root as #1; same recommended fix.
3. **VPPUT = 0 for non-oracle workloads** is structural (no ground-truth oracle
   for UI/codegen). Efficiency measurement applies to oracle-backed tasks (Lean).
